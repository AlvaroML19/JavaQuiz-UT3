# JavaQuiz-UT3

Concurso de consola con 6 preguntas sobre Java, divididas en dos rondas de 3.
Práctica de la UT3 de Entornos de Desarrollo (1.º DAW).

- Ronda 1 (preguntas 1 a 3): Integrante A
- Ronda 2 (preguntas 4 a 6) y resultado final: Integrante B

- Integrante B: Alvaro Martin Losa (AlvaroMartin219)

## Cómo ejecutarlo
1. Abrir la carpeta del proyecto en Visual Studio Code con el Extension Pack for Java.
2. Abrir `src/JavaQuiz.java` y pulsar **Run** encima del método `main`.
3. También por terminal, desde la carpeta del proyecto:
   javac -d bin src/JavaQuiz.java
   java -cp bin JavaQuiz
4. Responder cada pregunta escribiendo A, B o C (vale en mayúscula o minúscula).
